# Design

UI design for Bookmarked (desktop, 1440 px wide), made in Figma.

- **Figma file:** [Reading app](https://www.figma.com/design/mzLTnHp1biqSaJGp8yoEs3/Reading-app?node-id=0-1&p=f)
- **Snapshot exported:** 2026-10-17
- **Source of truth:** the Figma file. The images below are a snapshot and may be out of date. Re-export them after design changes (see the bottom of this page).

> The designs use the name "Marginalia" on some screens. The product name in this repo is still "Bookmarked" (temporary name).

## Updating the screenshots

In Figma, select a frame, open the Export section in the right sidebar, choose PNG at 1x and export. Save it in `screens/` with the same file name, so the links above keep working. To export everything as one PDF, use File → Export frames to PDF.
