# Book search (fuzzy, search-as-you-type) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Find catalogue books by title, author or ISBN despite small typos and missing accents, and update the Explore results while the reader types.

**Architecture:** Postgres `pg_trgm` + `unaccent` (migration 0009, GIN trigram indexes) behind `IBookRepository.search(query, limit)`. `GET /book?q=` replaces `GET /book?title=` for both frontend callers. `ExploreView` waits 300 ms after the last keystroke, writes `?q=` with `router.replace`, and cancels stale requests with an `AbortController`.

**Tech Stack:** Postgres 17 (`pg_trgm`, `unaccent`), Drizzle ORM 0.45 / drizzle-kit 0.31, Express 5, `node:test`; Vue 3, vue-router 5, Vitest + @vue/test-utils.

**Spec:** [2026-11-11-book-search-design.md](../specs/2026-11-11-book-search-design.md)

## Facts the engineer needs

- Backend commands run from `apps/backend`; frontend commands from `apps/frontend`. Local Postgres is the Docker container `bookmarked-db` (`docker compose up -d db` at the repo root). Backend integration tests use `DATABASE_URL_TEST` or `DATABASE_URL`, falling back to `postgresql://postgres:password123@localhost:5432/bookmarked_dev`. Run `pnpm db:migrate` before the tests.
- Backend tests: `pnpm test` (all), or a single file with `pnpm exec tsx --test tests/integration/book-repository.test.ts`.
- Frontend tests: `pnpm exec vitest run <path>`.
- `word_similarity` scores, measured on Postgres 17 (query → text):

  | Query | Text | Score |
  | --- | --- | --- |
  | `hary poter` | `harry potter and the philosopher's stone` | 0.600 |
  | `the hobb` | `the hobbit: there and back again` | 0.889 |
  | `saramgo` | `jose saramago` | 0.625 |
  | `dune` | `the dunes of mars` | 0.800 |
  | `dune` | `duke` | 0.400 |
  | `dnue` | `dune` | 0.200 |

  The default threshold (0.6) leaves "hary poter" exactly on the edge, so the threshold is set to **0.5** per transaction. Known limit: a swapped-letter typo in a 4-letter word ("dnue") is not found. Trigrams can't catch it, and that is accepted.
- `Book` has no authors (the `authors`/`book_authors` tables exist, but the entity does not load them). The SQL search joins authors, but the in-memory repository can only search title and ISBN.
- Commits follow conventional commits (`feat:`, `test:`, `docs:`). If the `my-skills:commit_writter` skill is available, use it for each commit.

```sql
-- F-EXP-01: fuzzy book search by title and author (pg_trgm), ignoring case and accents.
CREATE EXTENSION IF NOT EXISTS pg_trgm;--> statement-breakpoint
CREATE EXTENSION IF NOT EXISTS unaccent;--> statement-breakpoint
-- unaccent() is STABLE, so it cannot be used in an index. f_unaccent names its
-- dictionary explicitly and is IMMUTABLE. Supabase installs extensions in the
-- `extensions` schema and local Postgres in `public`, so both schemas are
-- looked up instead of hard-coded.
DO $$
DECLARE
  unaccent_schema text;
  trgm_schema text;
BEGIN
  SELECT n.nspname INTO unaccent_schema
    FROM pg_extension e JOIN pg_namespace n ON n.oid = e.extnamespace
    WHERE e.extname = 'unaccent';
  SELECT n.nspname INTO trgm_schema
    FROM pg_extension e JOIN pg_namespace n ON n.oid = e.extnamespace
    WHERE e.extname = 'pg_trgm';

  EXECUTE format(
    'CREATE OR REPLACE FUNCTION public.f_unaccent(text) RETURNS text '
      || 'LANGUAGE sql IMMUTABLE PARALLEL SAFE STRICT AS %L',
    format('SELECT %I.unaccent(%L::regdictionary, $1)', unaccent_schema, unaccent_schema || '.unaccent')
  );
  EXECUTE format(
    'CREATE INDEX IF NOT EXISTS books_title_trgm_idx ON public.books '
      || 'USING gin (public.f_unaccent(lower(title)) %I.gin_trgm_ops)',
    trgm_schema
  );
  EXECUTE format(
    'CREATE INDEX IF NOT EXISTS authors_name_trgm_idx ON public.authors '
      || 'USING gin (public.f_unaccent(lower(name)) %I.gin_trgm_ops)',
    trgm_schema
  );
END $$;
```

```ts
/** Below this length trigrams are unreliable, so only prefixes match. */
const TRIGRAM_MIN_LENGTH = 3;
/** pg_trgm's default (0.6) only just lets "hary poter" find "Harry Potter". */
const WORD_SIMILARITY_THRESHOLD = 0.5;

/** The ISBN digits in `query` (hyphens and spaces removed), when it looks like one. */
export function isbnDigits(query: string): string | null {
  const digits = query.replace(/[\s-]/g, '');
  return /^\d{10,13}$/.test(digits) ? digits : null;
}

function escapeLike(text: string): string {
  return text.replace(/[\\%_]/g, '\\$&');
}

/** Lowercase and accent-free, the same expression as the trigram indexes (migration 0009). */
const folded = (value: SQL | AnyPgColumn): SQL =>
  sql`f_unaccent(lower(${value}))`;

/** True when one of the book's authors satisfies `condition`. */
const anyAuthor = (condition: SQL): SQL =>
  sql`exists (select 1 from ${bookAuthors} join ${authors} on ${authors.id} = ${bookAuthors.authorId}
      where ${bookAuthors.bookId} = ${books.id} and ${condition})`;
```

4. Add the method to `DrizzleBookRepository`, after `findByTitle`:

```ts
  async search(query: string, limit: number): Promise<Book[]> {
    const text = query.trim();
    if (!text || limit <= 0) return [];

    const needle = folded(sql`${text}::text`);
    const prefix = sql`${folded(sql`${escapeLike(text)}::text`)} || '%'`;
    const title = folded(books.title);
    const authorName = folded(authors.name);
    const isbn = isbnDigits(text);
    const isbnMatch = isbn ? sql`${books.isbn13} like ${`${isbn}%`}` : null;
    const fuzzy = text.length >= TRIGRAM_MIN_LENGTH;

    const textMatch = fuzzy
      ? or(sql`${needle} <% ${title}`, anyAuthor(sql`${needle} <% ${authorName}`))
      : or(sql`${title} like ${prefix}`, anyAuthor(sql`${authorName} like ${prefix}`));
    const where = isbnMatch ? or(isbnMatch, textMatch) : textMatch;

    // Best first: ISBN, then a title starting with the query, then the closest title or author.
    const order: SQL[] = [];
    if (isbnMatch) order.push(sql`(${isbnMatch}) is true desc`);
    order.push(sql`(${title} like ${prefix}) desc`);
    if (fuzzy) {
      order.push(sql`greatest(
        word_similarity(${needle}, ${title}),
        coalesce((select max(word_similarity(${needle}, ${authorName}))
          from ${bookAuthors} join ${authors} on ${authors.id} = ${bookAuthors.authorId}
          where ${bookAuthors.bookId} = ${books.id}), 0)
      ) desc`);
    }
    order.push(sql`${books.title} asc`);

    return this.db.transaction(async (tx) => {
      // `<%` reads its threshold from this setting; `true` scopes it to this transaction.
      await tx.execute(
        sql`select set_config('pg_trgm.word_similarity_threshold', ${String(WORD_SIMILARITY_THRESHOLD)}, true)`,
      );
      const rows = await tx
        .select()
        .from(books)
        .where(where)
        .orderBy(...order)
        .limit(limit);
      return rows.map(toDomain);
    });
  }
```

```ts
  // Not fuzzy and title-only (Book has no authors): the integration tests cover real matching.
  async search(query: string, limit: number): Promise<Book[]> {
    const fold = (s: string) =>
      s.normalize('NFD').replace(/\p{M}/gu, '').toLowerCase();
    const text = fold(query.trim());
    if (!text || limit <= 0) return [];
    const isbn = isbnDigits(query.trim());
    const rank = (book: Book): number => {
      const title = fold(book.title.value);
      if (isbn && book.isbn13?.value.startsWith(isbn)) return 0;
      if (title.startsWith(text)) return 1;
      return title.includes(text) ? 2 : -1;
    };
    return [...this.books.values()]
      .map((book) => ({ book, rank: rank(book) }))
      .filter((r) => r.rank >= 0)
      .sort((a, b) => a.rank - b.rank || a.book.title.value.localeCompare(b.book.title.value))
      .slice(0, limit)
      .map((r) => r.book);
  }
```

```ts
// F-EXP-01: the search lives in `?q=`, so reload and back keep it. Typing searches
// 300 ms after the last keystroke (replacing the URL); Enter searches at once (pushing it).
const MIN_QUERY_LENGTH = 2;
const TYPING_DELAY_MS = 300;

/** The `?q=` a text leads to: trimmed, or '' when too short to search. */
function toQuery(text: string): string {
  const trimmed = text.trim();
  return trimmed.length >= MIN_QUERY_LENGTH ? trimmed : '';
}

const query = computed(() => (typeof route.query.q === 'string' ? route.query.q.trim() : ''));
const draft = ref(query.value);
const results = ref<LibraryBook[]>([]);
const searching = ref(false);
const searchError = ref(false);
let latestSearch = 0;
let inFlight: AbortController | undefined;
let typingTimer: ReturnType<typeof setTimeout> | undefined;

function routeTo(text: string) {
  const q = toQuery(text);
  return { name: 'explore', query: q ? { q } : {} };
}

watch(draft, (text) => {
  clearTimeout(typingTimer);
  if (toQuery(text) === query.value) return;
  typingTimer = setTimeout(() => void router.replace(routeTo(text)), TYPING_DELAY_MS);
});

watch(
  query,
  async (q) => {
    // Back, forward, Clear and first load fill the field; typing never gets overwritten.
    if (toQuery(draft.value) !== q) draft.value = q;
    inFlight?.abort();
    searchError.value = false;
    const id = ++latestSearch;
    if (!q) {
      results.value = [];
      searching.value = false;
      return;
    }
    searching.value = true;
    const controller = (inFlight = new AbortController());
    try {
      const found = await searchBooks(q, controller.signal);
      if (id === latestSearch) results.value = found.map((b) => mapApiBookToLibraryBook(b));
    } catch {
      // A cancelled search is always an older one, so this guard drops it too.
      if (id === latestSearch) {
        results.value = [];
        searchError.value = true;
      }
    } finally {
      if (id === latestSearch) searching.value = false;
    }
  },
  { immediate: true },
);

function search(text: string) {
  clearTimeout(typingTimer);
  void router.push(routeTo(text));
}

onBeforeUnmount(() => {
  clearTimeout(typingTimer);
  latestSearch++;
  inFlight?.abort();
});
```
